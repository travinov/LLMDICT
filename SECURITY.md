# Security policy

## Поддерживаемая версия

Проект находится на стадии MVP. Исправления безопасности применяются к последней версии ветки `main`.

## Что считать чувствительными данными

- API keys OpenAI, Sber SaluteSpeech и GigaChat;
- Apple signing certificates, provisioning profiles и private keys;
- реальные аудиозаписи, расшифровки и логи с пользовательским содержимым;
- BLE traces, если они содержат передаваемое аудио;
- device/account identifiers, не нужные для воспроизведения проблемы.

Приложение сохраняет provider credentials в iOS Keychain. Репозиторий игнорирует распространённые secret/signing-файлы, но это не заменяет проверку перед commit.

## Сообщение об уязвимости

Не публикуйте рабочий exploit, ключ или запись в публичном Issue. Используйте GitHub Private Vulnerability Reporting, если он включён для репозитория, либо свяжитесь с владельцем репозитория через его профиль GitHub и передайте минимальный воспроизводимый пример без персональных данных.

В сообщении укажите затронутый commit, модель устройства/iOS, влияние, шаги воспроизведения и безопасный способ проверки исправления.
