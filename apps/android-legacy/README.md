# Android legacy prototype

Это сохранённый ранний Android-прототип LLM Dictaphone. Он оставлен для истории миграции, сравнения data model и отдельных интеграционных решений.

Активный продуктовый код находится в [`../ios`](../ios). Android-прототип не входит в текущую hardware/iOS validation matrix и не должен восприниматься как поддерживаемый релиз.
